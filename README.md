# Smart Fishing Reminder System (C++)

This project implements the core decision-making logic of a smart fishing reminder system using C++.

## Description
The system evaluates assumed environmental inputs such as water temperature and light intensity to determine whether the conditions are suitable for fishing. The focus of this project is on control logic and embedded-style programming concepts.

## Features
- Threshold-based decision making
- Simple and reliable control flow
- Console-based input and output
- Embedded-style logic implementation

## Technologies Used
- C++

## Note
Sensor values are assumed as user inputs. Hardware integration and simulator development are not included in this project.
